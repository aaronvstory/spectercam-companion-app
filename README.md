# SpecterCam Companion

Desktop bridge: **OBS → iPhone over USB** (no full app needed). Also streams a file directly, or steps aside for Wi-Fi.

This repo hosts the **companion app releases + the auto-update feed**. Downloads are on the [Releases](../../releases) page:
- **macOS** — `SpecterCam-Companion-<version>.dmg`
- **Windows** — `SpecterCam-Companion-<version>-portable.exe`

Unsigned builds: first launch, right-click → **Open** (macOS) or **More info → Run anyway** (Windows SmartScreen). After the first install the app auto-updates itself with an in-app progress bar.
